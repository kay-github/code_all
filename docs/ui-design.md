# 工具站 UI 规范

以 [333 投资理论](../tools/investment-theory/index.html)为实现样板。新增页面或功能时，先确认用户最常看的数据和最常做的操作，再用下面的层级和组件组织页面。

## 主题与排版

- 引入 [`/assets/site-theme.js`](../assets/site-theme.js)和 [`/assets/workspace-theme.css`](../assets/workspace-theme.css)，分别沿用全站主题偏好和共用颜色变量。共用变量的取值以 CSS 为准。
- `--bg` 用于页面底色，`--surface` 用于卡片和明细，`--inset` 用于卡片内部或次级数据区，`--group-bg` 与 `--group-text` 用于需要突出层级的分组标题。浅色使用低饱和蓝灰，深色保留对应的层级。
- `--line` 用于轻分隔，`--control-line` 用于输入框边界，`--accent` 用于链接、选中和焦点，`--primary` 用于主要按钮。投资盈亏沿用红涨绿跌，同时显示正负值或明确文字。
- 正文以 15px 为基准，辅助文字 12–13px，区块标题约 20px。金额、百分比和证券代码使用等宽数字。常用间距为 8、12、16px，卡片圆角约 10px，边界主要靠底色和细线。

## 页面和组件

| 场景 | 样板 |
| --- | --- |
| 数据工作台 | 页面标题 → 标签导航 → 当前状态 → 核心摘要 → 分布和明细。将最高频的操作放在对应区块上方，相关次要操作靠近它。 |
| KPI 与图表 | 核心数值用字号或底色突出。实际值、目标和图例有明确标签。图表附带数值、单位和数据日期。 |
| 分组和明细 | 标题条有独立底色，放组名、数量和展开箭头。明细用较浅的内容面，每行依次展示标识、指标标签和值。折叠区使用原生 `details` / `summary`。 |
| 表单与操作 | 字段用可见标签，示例用占位文字，校验提示靠近字段或提交按钮。一组操作突出一个主要按钮。删除、覆盖等操作明确写出对象和后果。 |
| 状态与反馈 | 就近显示加载、待保存、成功、错误或空状态。空状态说明接下来可以做什么，错误提供适当的重试入口。颜色之外保留清晰的状态文字。 |
| 窄屏和键盘 | 优先让内容换行或把指标改成两列。触屏主要控件高度至少 44px，窄屏表单输入文字至少 16px。标签页支持方向键及 Home / End，焦点可见，滚动时为吸顶导航留出空间。 |

组件的实际结构和页面样式见 [333 页面](../tools/investment-theory/index.html)与 [333 样式](../tools/investment-theory/style.css)。新增页面按需要复用主题和组件结构，页面自己的布局放在自己的样式文件里。

## 上线前检查

- 用 320–390px 手机宽度、桌面宽度和放大后的页面检查深浅色。确认按钮可点、表单可输入、长名称和大金额可读，页面无横向滚动。
- 用键盘检查标签切换、焦点可见、折叠和弹窗。内容刷新后保留已展开的分组和正在操作的焦点。
- 分别查看空数据、正常数据、加载失败和同步冲突。确认用户能从状态文案判断下一步。
