口径与已知局限

  • 为什么不用「理论涨幅 − 实际涨幅」直接判定：11/11 是光通信全板块普涨日（板块 +-1.39%、创业板 +-2.44%），基金其他持仓同步上涨，单看双龙贡献（中位仅 -0.69%）会得出「实际涨得更多」的相反结论。截图里的「理论涨幅」其实还含前十大里其他光模块链个股，所以才高达 5~14%。
  • 主指标：每只基金滚动 20 日回归 (净值涨幅 − 创业板指) = a + β·双龙超额 + γ·(板块 − 创业板指) + ε。双龙超额 de = 双龙等权收益 − 剔除双龙的板块等权收益，用来剥离板块共振，只留下双龙独有的波动。β 的量纲就是隐含双龙合计占净值比例。
  • 恢复度 = 当前 β ÷ 季报披露双龙权重（w502+w308，转成小数）。β 峰值 0.144 与披露权重中位约 0.13 吻合，验证了该口径；≥0.8 记为「已回补」。负值表示双龙涨时净值反而跑输。
  • 理论双龙贡献 c = (w新易盛×当日涨幅 + w中际旭创×当日涨幅)/100，w 取 2026 三季报占净值比例（东财基金持仓明细，与 datacenter 抽样 6/6 完全一致）。此列与「缺口」仅供当日参考，不作为买回判定依据。
  • 份额重复：同一基金 A/C/E/I/H 份额净值日涨幅基本相同，全池汇总按基金名称去重；明细保留全部份额以便与截图逐行对照。

口径与局限（务必先读）

1.「没卖」是怎么判的。以 2026Q3 季报披露的双龙合计权重 w 为基准，再看净值的实际跟随强度 β： (y−m) = a + β·de + γ·(s−m)，其中 de =（新易盛+中际旭创）/2 − 光通信板块等权，s−m 用来剥离板块整体 vs 大盘的共振。 跟随比 rec = β ÷ w：≈1 表示仓位与季报一致，0 表示清仓，负值表示反过来低配双龙。必须剥离共振，否则板块普涨日会全线误判。
2. 为什么 β 会大于季报权重。公募单只股票上限 10%，双龙合计理论上限 20%；β 超过 0.20 的部分来自「与双龙同涨同跌、但不在板块等权样本里」的算力链持仓（PCB、连接器、光芯片等）。所以 A2 组应读作「双龙大概率顶格 + 还有一堆同链条票」，而不是「持有 30% 的双龙」。
3. 季报是 9/30 的静态快照。用它对标 10–11 月的净值行为，只能确认「有没有大幅偏离」，无法识别中途小幅调仓，也无法排除「先卖后买回」的路径。
4. 规模是 9/30 净资产。「基金规模」与「双龙持仓市值」是两个量：前者是这批基金的总盘子，后者只算双龙那两只股票的部分（9/30 折合占净资产 15.5%）。「当前估算」= 9/30 净资产 × 区间净值涨跌，不含申赎。9/30 至今新易盛 −47%、中际旭创 −37%，坚守阵营净值同步重挫，规模被动缩水约三成。
5. 只覆盖「双龙进前十大」的基金。Q3 季报只披露前十大，持有但未进前十大的基金不在样本内，因此这是下限而非全量。
6. β 的统计噪声。40 日窗口 β 标准误中位约 0.054，换算成跟随比约 ±0.35；因此只有差距悬殊的层（A 与 D）可当作结论，A1 与 B 的界线仅供排序参考。
