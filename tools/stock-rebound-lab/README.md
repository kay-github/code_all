# Stock Rebound Lab · 股票回撤研究室

线上入口：<https://1.688680.xyz/tools/stock-rebound-lab/>，工具站首页也提供入口。

本项目按在线功能页交付，沿用现有静态页面 + Vercel Node.js Serverless 架构，无需账号、Python 服务或桌面安装包。行情代理只接收股票与数据口径；个人持仓、债务、利润假设和研究档案仅写入用户浏览器。

## 精简界面与浪型推演（2026-11-02）

主导航只保留“价格测算 / 浪型推演 / 更多数据”。价格测算只输入参考高点、假设低点、从低点反弹比例与股数，主要输出目标价、涨跌幅与持仓市值。手机先显示测算器；图表均线、成交量和历史统计默认折叠。公司股本、利润、PE、持仓成本、现金债务和历史回测均放入“更多数据”，原有本机记录继续可用。

浪型为用户手动指定的情景，所有价格锚点必须使用同一复权口径，不做自动数浪或确认未来走势：

- **ABC**：A 长度 = A 起点 − A 假设终点；B 目标 = A 假设终点 + A 长度 × 回补比例。回补 A 跌幅的比例不等于从低点上涨的比例，两者分别显示。可选 C 目标 = B 目标 − A 长度 × C/A 长度比例；非正价格明确提示假设无效，不输出假价格。
- **五浪**：五浪目标 = 四浪假设底部 +（三浪终点 − 三浪起点）× 五浪/三浪长度比例。这是按用户截图选择的一种长度对照假设，比例可改，不代表通用数浪结论。
- 两种情景均支持自定义比例、共享持股数量、价格路径示意、保存/载入、导出 Excel，以及一键将按低点计算的涨幅应用到价格测算器。
- 新易盛截图示例：ABC 的 618.87→190，B 回补38.2%为353.82834元，实际从低点上涨86.2254%，7000股为2,476,798.38元；五浪用33.5→618.87、四浪192，0.786倍为652.10082元，1倍为777.37元。190、33.5、192仅初始化新易盛的研究假设，其他股票不继承。
- 参考说明：[TradingView 浪型与比例工具](https://www.tradingview.com/support/solutions/43000653212-elliott-wave-theory-and-tools/)。比例关系只用于情景计算，不是可靠预测概率。

## 使用与本地运行

线上打开即可使用。默认新易盛，左侧搜索覆盖沪深京 A 股，支持名称、关键词、六位代码及 `300502.SZ` 格式。手机横向滑动自选与功能导航；宽屏显示图表和模拟器双栏。

Windows 本地需要 Node.js 22+，双击仓库中的 `scripts/start-stock-lab.cmd`，或在仓库根目录运行：

```powershell
npm run dev:stocks
```

打开 <http://127.0.0.1:8765/tools/stock-rebound-lab/>。此启动方式不需要额外 npm 依赖；根项目的其他工具依赖仍按原项目安装。关闭终端或按 Ctrl+C 停止。`PORT` 环境变量可更换端口。

## 行情与复权的重要约定

1. 主行情：腾讯 `qt.gtimg.cn`，备用东方财富 `push2.eastmoney.com`；主历史：东方财富 `push2his.eastmoney.com`，备用腾讯 `web.ifzq.gtimg.cn`，向过去分页直至源起点或预算/分页上限。搜索优先东方财富建议接口，备用腾讯smartbox。实现直接适配AKShare公开文档所述的原始源，不在Vercel安装Python/AKShare。
2. 日线成交量统一为**股**，金额为**元**；公司市值与利润单位为**亿元**、总股本为**亿股**。腾讯字段73为总股本、字段72为流通股本，不能混用。
3. 前复权可能因累计现金分红产生零或负的早期价格。这种价格无法用于比例回撤。若主备源的前复权均不可用且至少一个出现非正价格，整段请求后复权；`adjust`、`basis`和警告明确说明实际口径。
4. 后复权的价格预设/历史路径映射使用**同一来源、同一已完成交易日的不复权收盘 ÷ 后复权收盘**作为整条曲线的缩放系数，使价格映射具有当前元/股的含义。该曲线称“后复权等比归一参考”，**不是传统前复权**。历史回撤仍在原后复权曲线上计算，等比缩放不改变回撤百分比。无法获取同日原价时不提供这个归一参考。
5. 前复权随分红送转重算，后复权因来源修订也可能更新；缓存到期后整段替换，不增量拼接旧复权段，避免历史曲线失真。源可能截断时明确提示分析仅限可得区间。
6. 不复权保留当时成交价格，适合核对历史原价，跨除权日的回撤可能为机械跳空，页面会提示。
7. 新易盛初始194元起涨价、7000股、180亿元利润是用户需求给定的**演示研究参数**，不是最新行情或实际持仓。618.87元只是需求参考，代码不把它硬编码为计算高点；高点由行情计算。其他股票不继承这些参数。
8. 无付费行情授权、Level-2或交易保证；公开上游可能改变接口、限制境外IP或停服。主备都失败且没有缓存时，页面明确报错，计算器和CSV导入仍可使用。

数据文档：<https://akshare.akfamily.xyz/data/stock/stock_quote.html>。图表采用TradingView Lightweight Charts 5.2.1，源库Apache-2.0许可与NOTICE保留在`vendor/`，页面有来源链接；无外部CDN运行依赖。

## 算法约定

- **最大回撤**：逐日维护此前高点；先比较当天收盘/最低与此前峰值，再更新峰值，保证低点日期严格晚于峰值。收盘口径高低都用收盘；日内口径用过去最高与后续最低。恢复时间从低点之后第一个触及前高的交易日计算。
- **深跌周期**：以此前峰值为锚，首次超过阈值后进入周期，整轮最低点更新；恢复该轮前高后结束，未恢复保留进行中。日内如果一天同时创新低且触及前高、收盘却未恢复，不推断高低先后，延后确认恢复。
- **阶段反弹**：从此前低点上涨20%才确认，之后自阶段高点回落10%结束一段；低点、峰值和最终底部是事后研究，不是当时已知信号。后续再创新低只统计当前所选区间内数据。
- **事件研究**：信号只用当日和过去信息；高点参照截至前一日的全部或滚动120/250日最高。触发日收盘为比较基准，下一交易日开始观察。最低价触及也不假设成交在最低价。前20日均量不含信号日，放量为1.5倍。
- “首次穿越”按前一日是否已低于该阈值判断；未满足放量的首次触及不会向后补触发。去重以信号日+观察窗口为锁定区间。期末不足固定交易日的样本保留展示但不参与统计；当前日北京时间15:05前不入回测。
- MFE/MAE是窗口内最高/最低相对信号日收盘的变化，无需强制归零。触及20%/50%比例是相对信号日收盘。未计回测成交成本、滑点、涨跌停或停牌流动性，不能当作策略实际收益。少于10个完整样本明确显示不可靠。
- 388元示例：`194 × 2 = 388`；`388 × 7000 = 2,716,000`元；`388 × 13.95 = 5,412.60`亿元；`5412.60 ÷ 180 = 30.07`倍。
- 极端映射不提前四舍五入：`618.87 × 23.2% = 143.57784`元，反弹110%为`301.513464`元，显示301.51；若先将低点舍入143.58再计算会显示301.52，文档近似值与此略有区别。
- 假设PE对非正利润不适用；未填利润保留为空。市值模拟假定总股本不变。债务字段要求填写待还**本息合计**；普通借款不推算强平价，融资融券也因缺少担保参数不输出强平线。

## API

同源只读`GET /api/stock`：

| 参数 | 示例 | 结果 |
| --- | --- | --- |
| `action=search&q=中际` | 代码、中文名、关键词 | `items[]`: `symbol,name,exchange` |
| `action=quote&symbol=300502.SZ` | 沪深京代码 | 最新可得行情、单位、`time,source,delayed,cached` |
| `action=history&symbol=300502.SZ&adjust=qfq` | `qfq / hfq / none` | 完整日线、实际`adjust`、`requestedAdjust,basis,referenceScale,referenceDate,warning,complete,fetchedAt` |
| `force=1` | 与以上参数组合 | 绕过服务端有效缓存，主备仍失败时可返回明确标记的旧缓存 |

不接受自定义上游URL、Token或跨域代理目标。行情/搜索/历史内存缓存分别25秒/1小时/20分钟；Vercel CDN对应短缓存。缓存不是持久云数据库，本机IndexedDB才负责离线持久化。API不写个人金融参数。

## 导入、导出与限制

“更多数据 → 情景与备份”和侧边栏可以导出数据；手机侧边栏为横向自选，导入/备份入口也可从“更多数据 → 情景与备份”进入。JSON备份会覆盖同名本机记录，导入前建议先备份。每只股票/复权口径使用独立键；备份版本为1，不兼容未知版本。

历史CSV头部示例（`volume`为股、`amount`为元）：

```csv
symbol,adjust,time,open,high,low,close,volume,amount
300502.SZ,qfq,2020-01-02,10,11,9,10.5,10000,105000
300502.SZ,qfq,2020-01-03,10.5,12,10,11,20000,220000
```

也支持中文`日期/开盘/最高/最低/收盘/成交量/成交额`，但必须提供`adjust`列；没有symbol列时视为当前股票。拒绝混合股票/复权口径、非法日期/OHLC、超过20MB文件或12000条单股日线。导入数据显式标记为用户数据、未验证真实性。完整JSON备份恢复后会异步尝试刷新行情。

离线需先联网访问一次以缓存页面和已查看行情；清空浏览器数据、更换设备/浏览器或无痕模式可能移除本地记录。无自动云同步；用JSON备份迁移。没有SQLite或EXE，在线版本用浏览器数据库替代本地原生数据库；不提供Tushare Token、港美股、机构预测、多股票回测、券商交易或强平线。分析报告为可打印HTML，可由浏览器“打印 → 另存为PDF”。
