# 量能观察台

独立入口 `/tools/volume-lab/`，静态 HTML/CSS/ES modules + 本地 Apache ECharts 6.1.0。无需增加前端构建框架；原金融工作台的两个量能图和模型被抽取为独立实现，保留指标口径。原项目源码、服务版本、提醒和推送保持原样。

## 数据

- 同源只读 `GET /api/volume?action=detail|history|search|catalog&symbol=510300.SH`；沪深股票、场内ETF分类校验，拒绝指数及用户指定上游地址。
- 数据适配层仅从固定的金融工作台公共读取接口取得数据，显式选择量价字段；不透传 rules、positions、接收人或账户配置。个人自选和布局只保存在本浏览器 `volume-lab-v1`。
- 原采集服务未登记品种时，分钟降级为腾讯可得近五日，标签明确为短历史，不冒充20日。日线可走原只读叠加接口。新关注品种不会自动改变服务器自选。
- 本轮通过既有服务器本机管理 API 添加 510310、300750 自选，使用原 Monitor 继续采集；不创建提醒。实际11月3日初验510300/300502/300308各20样本，510310为11，300750为4；未来以响应实际样本为准。
- 历史量能沿用原 `volumeHistory.ts`：全历史预热后裁剪60/120/250日；已收盘均量含该日，盘中未收盘日不入均线，按历史响应获取时间判定。若上游日K仅到昨日，明确显示最近日日期，不生成假日K。
- 股票量为股、ETF量为份，腾讯手数乘100。5分钟窗口不穿午休；缺口不补0。报价和分钟完成时间分别显示。

## 请求与资源

单图盘中1次读取，双图2次；历史视图每标的另1次日K读取。相同标的同批去重。交易窗口可见时每轮完成后60秒再调度；隐藏/离线/离开中止。午休及周末仅手动刷新。前端12项LRU、闲置5分钟；服务端80项缓存并复用在途请求，detail20秒/history60秒/search1小时。旧缓存最多回退24小时且显式标记。图表按数据签名更新；切换单图释放第二张实例，页面离开释放观察器、图表和数据引用。

## 验证与发布

`npm run dev:volume` 打开 `http://127.0.0.1:8766/tools/volume-lab/`；`npm run test:volume` 验证纯计算与只读适配。发布前运行相关全站回归及 `vercel build --yes`，推送main后核对生产Ready与实际域名。

首页新默认卡片同时需加入已有私有Blob配置；`scripts/add-volume-home-entry.cjs` 从忽略的env文件读取凭据，更新前备份，使用ETag条件写入，仅追加入口，保留原有全部配置。不得提交env或备份文件。
