怎么读这两种数浪

  1. 先定级别和起点。从同一个高点出发，ABC 表示下跌、反弹、再下跌。另一种解释把相同的前两段标为第1和第2浪，并继续观察第3、4、5浪。ABC 的 C 浪自己也可能细分成五段。
  2. 比较点数长度。C/A＝（B浪高点－B后最低点）÷（起点高点－A浪低点）。0.809、1.0 是原帖观察上证时用的参照。1.618 是延伸第3浪的经验比例。普通推动浪要求第3浪不能短于第1与第5浪两者，第4浪不能进入第1浪价格区间。楔形等其它变体需人工复核。
  3. 用后续走势区分。ABC 案以两日连续收在末段前高之上作为完成的支持；若再创新低，就更新末段低点。五浪案以11月20日当时可知的 B 后最低点作初始锚点，顺查其后的收盘是否回补候选第3浪跌幅的23.6%，再看是否出现弱反弹后破底。百分比和连续收盘规则是工具的量化约定。
  4. 分开看反弹的分母。整段下跌的38.2%回补＝末段低点＋（起点高点－末段低点）×0.382。该水平会随低点重算，属于观察线。试算用指数日线的盘中高低点，信号按收盘核对。

锚点以日线高低价对齐。上证的前三锚点来自博主公开点位。创业板大级别锚点结合原帖和公开讨论回查，双创 A/B 和 C1–C4 用视频画线和日线高低价对齐。科创50的19周参照取11月3日低点，周内穿越和周收盘确认分别记录。
