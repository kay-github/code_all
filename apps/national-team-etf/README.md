# 国家队ETF观察 v2.1

核心目标：尽量准确地跟踪国家队等政策性大资金可能经过的ETF通道，并连续保存申赎、分通道减仓及恢复过程。发现线索和确认身份分别处理：不把所有赎回归给国家队，也不因主体未知就取消已有风险观察。

## 当前依据

- 当日核心15只优先使用沪深交易所直接披露份额；金额按相邻日份额变化乘当日不复权成交均价估算。
- 交易所份额、金额估算、主体身份是三种不同结论。份额减少能确认；实际现金流、赎回者身份和全市场仓位不能由此还原。
- 截至2026-11-13：核心15只中12只份额减少、3只增加，敞口估算约−103.42亿元，5日约−320.12亿元。正式份额风险状态为“流出加速”，主体未确认。此为该业务日观测，不是长期固定结论。

运行依赖：Python 3.11及以上、Node.js 20及以上、Git；核对部署状态使用已认证的Vercel CLI。采集与计算不需要额外Python第三方库。

## 正式份额口径

`v2_exchange.py`负责采集、单位检查、累积和修订记录。

- 上交所：ETF基本信息的清算后份额，`TOT_VOL`单位万份，默认接口最近10个交易日。
- 深交所：`scsj_fund_jjgm`接口，`size_date`是业务日，`current_size`单位万份。接口明确T日晚间值仅供参考，以T+1早间更新为准。按此业务日记账，不沿用第三方平台过时的一日平移规则。
- 相邻日必须来自同一交易所、同一份额口径；缺一个端点就不计算单日流量。5日必须有6个连续份额端点及5天有效价格。15只不齐不展示核心完整合计。
- 正式历史会跨接口窗口持续累积，不因第11天被接口移出而丢失。新公布资料修订旧值时整段重新计算，旧版本仍可查。
- 不将交易所总份额与供应商未核实的换手率分母拼接。正式份额和历史反推是两条各自一致的序列，可对账、不可混接。

## 金额、单位、日期

正式份额敞口估算＝（当日份额−前日份额×已核验份额行动比例）×当日不复权成交均价。金额单位亿元；成交均价＝成交额÷成交份数，不能以复权价代替。

历史反推份额＝成交量(手)×10000÷换手率(%)。只使用不复权日线，换手率舍入范围为±0.005个百分点；累计误差使用共享端点，不把每日误差当作独立误差简单相加。该范围不覆盖分母日期、范围差异、数据修订等系统误差，不是统计置信区间。

初始缺前值不记0，缺交易日不把多日差分塞进某一天。OHLC/金额/成交量不相容的记录隔离；未登记的疑似份额合并也隔离。510310在2024-09-23按正式0.49977589比例换算相邻比较单位，不单边缩放历史成交金额。

不把盘中最新一行当收盘；周末及长假保留两条指数日线共同确认的实际业务日，页面明确数据日。数据源不同步时停止，不猜日期。交易所数据已到更新日期而行情仍停在旧日时，发布检查拒绝覆盖线上。

## 样本和识别

核心15固定，包括510330和512050；境内扩展池61只。跨境和非股票基金排除。当前目录发现按成交额前100、估算规模前100、5日份额增幅前50和可识别指数家族取并集补历史；新候选不悄然改变固定历史分母。池变化需修改注册表版本，保留新增理由、正式基金资料、类别和反例。供应商分页完整不等于交易所全市场覆盖，新上市或未收录ETF可能遗漏；后续须与交易所全量目录交叉核对。注册表修改后必须重新完整采集，不能用旧批次冒充新样本池。

身份等级：I0未知；I1核心通道角色；I2已核验历史持有人或关联资料；I3同日实名交易。历史持有、匿名机构比例、放量、同步申赎均不能独自确认当日国家队买卖。资料须保存来源、发生日、公布日和核验状态，不把未来披露用于过去判断。无真值校准，不输出国家队概率或身份准确率。

## 分通道风险

`v2_tracking.py`用正式份额独立计算每只ETF、核心家族和核心池的5/10/20日净变化、规模占比、已观察份额回撤和持续状态；历史反推状态单独保留。份额历史未满63日时明确标注已观察日数，10/20日不足不补值。

规则在`config/rules.json`，版本2.1。小额负变化保留；稳健累计流出、规模占比和持续性共同升级为持续流出或加速。0.5%/1%/2%是研究阈值，不是已验证最优值。身份未知、成本以下、政策表态或下跌市场都不关闭预警。

事件保留起点和最高等级。一次申购不解除旧观察；连续5天的5日和10日累计均稳健转正后才可解除。缓慢但持续回补也可解除；缺数据保留记忆。单日流量比例统一除以前日规模。后续检验严格按未来10个交易日取值，缺日不跨过去补足样本。

## 持续进化纪律

每次调整记录：触发问题 → 原始证据与时点 → 替代解释 → 修改的口径/代码/阈值 → 同样本前后对比 → 回归结果 → 尚未证实事项。改数据源不等于模型变准；阈值变化必须说明误报、漏报和发现延迟的变化，不能只挑有利案例。

持续保存首次线索、升级、回补、解除、数据修订及未来5/10/20日结果。后续申赎只验证通道预警用途；实名披露才用于检验身份。当前历史回放使用修订资料，不冒充真实发布时点的样本外回测。无法由份额恢复国家队成本、库存批次、实现收益或全部二级市场交易。
