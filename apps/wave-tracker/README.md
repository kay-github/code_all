## 样本外检验

2025-01-01 至 2026-11-20 的逐日收盘回放。原始日线从 2023-08-02 开始，个股用腾讯前复权，指数用腾讯价格指数。在每个日期重算确认转折，并与全量数据中过滤掉未来确认日的结果逐日比较。发现只用最新三个锚点会漏掉仍在发展的第4、5浪，现使用多候选和确认时点排序。第二组未参与这项修正。

另检验终点后的价格路径。比较 23.6% 反抽基线与额外要求 C/A ≥ 0.809 的筛选，统计20日内先走到整段38.2%参考位，或先刷新当时的极值。独立第二组已分胜负样本分别为 23/52（44.2%）和 15/28（53.6%）。两组包含重叠，未决和信号当日已达目标的样本单列。当前有效性结论覆盖可复现画线和候选冲突检查，比例筛选的预测增益还没有足够证据。波浪没有唯一的事后标签。样本中的现行前复权系列可重现这次实验，复权因子没有独立的逐日历史版本。

三条独立样本便于手工复查：

- 中证医药下跌，回放到 2025-06-18，以 2024-12-12、2025-01-13、2025-04-01 做首三锚点。第4浪反弹高 8293.46 进入第1浪区间，排除这一普通五浪计数，C/A 为 0.851。
- 中证消费下跌，2026-03-16 时看到六个候选端点，3/1 为 1.330。该案例的第5浪长度较短，普通五浪硬约束允许这一方案。
- 兖矿能源上涨，2026-05-14 时可重现推进的五段候选，3/1 为 2.735。整个结构在同一前复权口径下比较。

`replay.mjs` 实测两个方向，重算报告时传日线快照目录和输出路径，可加 `heldout` 选择独立组。报告包含源数据哈希、每个标的的候选状态计数与冻结的信号日。`scenarios.mjs` 的脚本与网上的画线模块共用。研究股票放大时期差、复权基准和观察尺度都应随结果留档。正式走盘中的数据不参与收盘判断。
