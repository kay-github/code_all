# 双龙回补跟踪：证据、模型与口径

版本：3.0，2026-11-14。对象为主动公募对新易盛与中际旭创的披露持仓及最新收益关联。

## 证据等级

基金管理人的定期报告可以确认特定期末的组合持仓；供应商定报反查属于第三方整理；净值和收盘行情只能帮助推断收益暴露。三者不能互相替代。

报告期末持仓也不是报告发布日的实时仓位。未在前十大出现、反查未见、某份额没有独立净值，都保留未知。股数变化仍可能包含送转、份额合并和其他公司行动，不能不经核验就叫主动净买卖。

监管部门对模拟估值、持仓披露滞后已有说明：[深圳证监局](https://www.csrc.gov.cn/shenzhen/c105614/c7602038/content.shtml)。收益风格分析依赖因子和样本假设，见 [Sharpe 原文](https://web.stanford.edu/~wfsharpe/art/sa/sa.htm)。这些依据不提供本项目的实际仓位识别精度。

## 样本与日期

样本为最近两个已结束季度的目标股持有人反查并集，加原始119个种子条目。不设置7.7%等高权重门槛，不因名称含科创/创业板就排除主动基金。目录类别区分主动、指数增强与纯被动产品。指数增强纳入观察池，显示披露与收益变化，但不据净值确认主动回补；纯被动指数不进入主动候选池。

名称末尾 A/C 等只用于暂定观察组；保留人民币/美元、LOF和持有期限。没有原报份额关系证据时，不称为已核验的独立基金数量。代表份额按净值新鲜度、来源可用性、覆盖和种子身份选择，不按模型系数或披露权重挑有利份额。

业务日以两个指数的同源已完成日线共同确认。模型按交易日窗口对齐，不把最后20条跨很久的净值称为最近20日。缺当前净值不能生成当日信号。供应商公布收益缺失不记0；缺相邻交易日不把跨日收益当作单日；已说明分红/拆分保留公布收益，未说明的单位净值与收益差异超过0.15个百分点时隔离。此容差仍需通过更多原报样本继续核验。

## 自由市场暴露模型

令 T=(两只目标股日收益的均值)，C=(新易盛−中际旭创)/2，P 为剔除双龙的产业链篮子，M/G 为沪深300/创业板。基金日收益均以百分点计：

`R = a + b(T−P) + kC + uP + vM + wG + e`

所有系数自由估计，不强制股票/市场暴露合计为1。两只股票对应的模型敏感度为 `(b+k)/2` 与 `(b−k)/2`，合计 b；这只是收益模型中的分解，在遗漏持仓、交易与因子不完整时不等于真实持仓权重。负 b 不证明做空、清仓；正 b 不证明买入。

宽篮子52个、窄篮子14个候选成分固定在配置中。每次以近80日完整复权收益的固定成分估计，避免窗口内成分变动制造虚假暴露变化。完整成分不足配置数量的90%时不给该模型结论；所有缺失成分对外披露。不用 `day` 冒充缺失的 `qfqday`。行情提供者的历史修订仍是来源风险。

20/40/60日分别估计。窗口至少90%有效交易日且末日有效。标准化设计矩阵条件数上限50，目标独有残差收益标准差至少0.35个百分点；矩阵秩不足、共线或独有波动不足时标记不可辨识，不把大系数当作大仓位。

## 变化、区间与线索等级

变化比较前20日与后20日，窗口不重叠。用联合回归允许两个窗口的全部控制系数分别变化；变化标准误来自同一个 HAC 协方差矩阵，保留跨边界相关。HAC滞后3按真实交易日距离计算，缺日不压缩为连续观测。1.96倍标准误构成近似区间；短窗口、非正态和结构变化都可能使区间失准。

每组取宽窄两套变化检验较大的双侧 p 值，再对所有观察组做 BY 多重比较修正，研究阈值0.10。因为 p 值来自短窗口近似模型，不能声称实际交易识别错误率受严格控制，也不能把修正 p 当作买入概率。组内相关、模型遗漏和不完整份额关系仍有影响。

较强候选同时要求：宽窄变化均可辨识且区间下限大于0、增量至少0.03、最近系数均为正、40日模型R²至少0.15、BY修正通过、顺序留出解释增益非负、个基对照通过。0.03等是研究阈值，不是已校准的市场最佳值。

初步升温不满足全部门槛；点估计变化、负向关联缓和、模型分歧继续保留观察，不冒充高确信回补。个基对照未获支持会降级，资料不足单独说明。没有达到门槛不等于没有建仓。

## 留出与个基混淆对照

近60日中的前50日拟合、之后10日检验；最低训练45日、检验9日。比较含双龙因子与仅市场/产业控制的预测均方误差。这个检验使用顺序留出收益，不是实际持仓真值；候选筛选仍看过同一段当前数据，不能称为独立盲测命中率。

对优先候选补抓其最近期前十大，剔除双龙，按披露权重构成固定的其他重仓股篮子，再加入宽窄模型。近80日完整复权行情须覆盖已知其他重仓股权重至少90%，且至少两只成分，否则为资料不足。加入额外控制后两套变化区间仍为正且可辨识，才算该对照通过。

这一步检验“是否可能只是其他重仓股驱动”，不证明当前仍持有这些股票。前十大之外持仓未知、旧权重、基金交易和遗漏的个股因子仍可能混淆；通过不等于确认回补。优先对照上限80组，未覆盖候选显式待核查。

## 原报样本与持续复核

宏利复兴001170/017612的2026三季报由管理人编制，镜像PDF见 [原报](https://static.howbuy.com/gkxx/ggfile/2026/2026-10/2026-10-27/5618512.pdf)。已查看第2、3、8页图像，核验组合关系、A/C资产、股数、市值和权重。A类29.27亿元是份额类净资产，不能称为份额数量或基金总规模；双龙权重分母应为A/C组合总资产68.0855亿元。

只有一个原报样本核验，不代表整池第一手核验。每次运行重解析全部供应商净值与持仓响应并检查哈希，这证明解析与展示一致，不能证明供应商数据本身绝无差错。

规则、来源、代码变更后全量重算当前窗口，不把旧95日“峰值回补率”接入新链路。历史研究要同时留存当时样本池、披露发布时间和修订版本；当前回溯结果不当作当时可得的实时结论。真实后验资料到来后才评估线索命中与漏报，不以模型自我拟合作为正确答案。
