访问密码

写操作需要一个项目通用密码，由站主发给可信的人。密码只保存在本机浏览器 localStorage，不上传到第三方；不需要填写后台的机器密钥。没有密码也可以看状态，但不能改开关、跑数、测试推送、添加板块。

立即执行

“立即跑一次”会触发 GitHub Actions 的 top-radar-daily.yml（workflow_dispatch）。需要在 Vercel 配 GITHUB_DISPATCH_TOKEN（actions:write + contents:write）；没配时接口会返回 503，不影响每天自动跑。

板块开关

休眠 = 不抓数、不算分、不推送，但保留历史。新增板块后默认监控中；第一次跑数后才会出现完整历史。

板块ID状态档位业务日监控

新增板块

填名称和代码列表。代码一行一个或用逗号分隔；系统会自动抓名称、校验代码，写入配置。保存后下一次跑数（或点“立即跑一次”）开始计算。建议主题板块 20–60 只，龙头和二线都放。

添加不会立刻产生历史；下一次跑数会回补 2020-12 起的数据。

推送规则（只读）

红色 / 深红：档位变化当天即时推，单次。
橙色：进入橙色推一次；之后每 7 天最多补一次“仍在橙色”，不每天推。
解除：从橙色及以上回到正常 / 观察，推一次。
不推：正常 ↔ 观察之间切换；同一天同一板块只推一次；数据超过 2 个交易日视为 stale，不推。
推送走 Vercel PUSHPLUS_TOKEN，单推，不建群组。
